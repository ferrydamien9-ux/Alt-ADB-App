# Alt-ADB Mobile (APK)

This is the Android-native version of Alt-ADB. It allows you to manage other Android devices directly from your phone!

## 📱 App Features
- **Native UI:** Built specifically for mobile touchscreens.
- **No PC Required:** Use your phone as the ADB host.
- **Lightweight:** Minimal battery drain.

## 🛠 How it's built
We use **Kivy** and **Buildozer** to compile Python code into a native Android `.apk`.
