# 📱 Alt-ADB Mobile (Beta)
**The ultimate Android-to-Android bridge. No PC required.**

Alt-ADB Mobile brings the power of the Android Debug Bridge directly to your pocket. Built for developers, power users, and the Alt-OS ecosystem.

---

## 🚀 Key Features
* **Zero-PC Setup:** Run ADB commands from one phone to another using a USB-OTG cable or WiFi.
* **Modern UX:** A clean, dark-mode interface designed for touch, not a terminal.
* **One-Tap Device Scan:** Instantly see connected devices and their status.
* **Built with Python:** High-performance logic powered by `adbutils` and `Kivy`.

## 🛠 Planned for January 1st Launch
- [ ] Full Logcat viewer (Mobile)
- [ ] Wireless Debugging (QR Code pairing)
- [ ] File Explorer (Push/Pull files between phones)

## 📥 How to Install
1. Go to the **Releases** tab on this repository.
2. Download the latest `.apk` file.
3. Open the file on your Android device and tap "Install" (Allow "Install from Unknown Sources" if prompted).
